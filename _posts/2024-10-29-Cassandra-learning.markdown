# How 
Systems like Cassandra are designed for these challenges and seek the following design objectives:

## Full multi-master database replication

## Global availability at low latency

## Scaling out on commodity hardware

## Linear throughput increase with each additional processor

## Online load balancing and cluster growth

## Partitioned key-oriented queries

## Flexible schema


## Dynamo
1. Dataset partitioning using consistent hashing
2. Multi-master replication using versioned data and tunable consistency
3. Distributed cluster membership and failure detection via a gossip protocol
4. Incremental scale-out on commodity hardware
