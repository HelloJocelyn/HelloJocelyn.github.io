## Learning curve
### Warm up level:

1. Develop skills in programming (my advice for beginners will be Python), learn about mechanical assembling and electronics.
* Corey Schafer’s Python for Beginners Playlist
2. Implement the knowledge on a micro-controller unit (popular choice is Arduino).
* Exploring Arduino: Tools & Techniques for Engineering Wizardry

This is not ideally robotics but it lays a good foundation for one to further advance in the field.

### Beginner level:

1. Learn object-oriented programming (OOP), data structures, and basic algorithms.
*  Data Structures and Algorithms with Python
* Data Structures & Other Objects using C++
(There is also a book by the same author for Java.)
* Introduction to Algorithms
2. Familiarize yourself with Linux operating system.
* LINUX: Easy Linux For Beginners
3. Learn more maths, physics, linear algebra, and probability.
* Khan Academy Playlists for each
4. With better knowledge of coding, circuitry, theoretical concepts, and familiarity with Linux, implement these on a smaller computer -Raspberry Pi or the BeagleBone.
* Make a Raspberry Pi-Controlled Robot: Building a Rover with Python, Linux, Motors, and Sensors
Intermediate level:

### Learn about more advanced theoretical concepts.
1. Introduction to Robotics: Mechanics, Planning, and Control
* Probabilistic Robotics
* Adrian Rosebrock’s course on Computer Vision
* Python: Machine Learning
2. Familiarize yourself with Robot Operating System
* Programming Robots with ROS
* Mastering ROS for Robotics Programming

## Books
https://github.com/manjunath5496/Robotics-Books/tree/master

"Robot Building for Beginners" by David Cook: This book is a great starting point for beginners and covers the basics of robot building using inexpensive materials and simple tools.
"Robotics: Everything You Need to Know About Robotics from Beginner to Expert" by Peter Mckinnon: This book provides a comprehensive overview of robotics, starting from the basics and progressing to more advanced concepts.
"Make: Electronics: Learning Through Discovery" by Charles Platt: While not solely focused on robotics, this book provides a solid foundation in electronics, which is essential for understanding and building robots.
"Arduino Robotics" by Warren, John-David: This book focuses on using Arduino microcontrollers to build robots and is a good resource for beginners interested in programming and electronics.
"Learning Robotics Using Python" by Lentin Joseph: This book introduces robotics concepts using the Python programming language, making it a great choice for beginners with some programming experience.
