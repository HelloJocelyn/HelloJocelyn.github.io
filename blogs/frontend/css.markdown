color, background-color, border-color,

## Spacing and Alignment

## Visual Hierarchy and Proportions
CSS also plays a role in defining visual hierarchy using font sizes (font-size), weights (font-weight), colors (color), and positioning (position, z-index). Developers can use CSS Grid or Flexbox to create hierarchical structures within the layout

## Animations and Transitions
transition and @keyframes
It supports smooth changes between states (e.g., hover effects, fade-ins, sliding effects) and is often used to enhance interaction design.

## Responsive Design
CSS supports responsive design through the use of media queries, which allow different styles to be applied depending on the screen size, orientation, or resolution

## Accessibility
CSS also includes tools to help with accessibility, like controlling contrast using color and background-color, ensuring text resizing with rem and em units, and supporting high-contrast themes.
