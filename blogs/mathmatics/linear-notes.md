# linear notes
1. 线性组合（linear combination）：V中向量组v1,v2...vm的线性组合是形如： a1v1+a2v2+...+amvm
2. 张成空间（span）：V中向量组v1,v2...vm的所有线性组合所构成的集合称为v1,v2...vm的张成空间，计作span（v1,v2...vm）。 换言之：span（v1,v2...vm）={a1v1+a2v2+...+amvm:a1...am <R }
3. 有限维向量空间(finite-dimentional vector space):如果某个向量空间可由某个向量张成，则称该向量空间是有限维的
4. 多项式(polynomial):$p(F)$: 
    1. 对于函数p:F->F,如果存在 $a1,...,am \in F$,使得对所有 $z \in F$都有 ： $p(z) = a_0 + a_1z + a_2z^2 + ... + a_mz^m$, 则称$p$为系数在z中的多项式。
    2. $p(F)$是系数在F中的全体多项式所构成的集合
