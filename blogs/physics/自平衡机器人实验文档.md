# 自平衡机器人实验文档

**实验名称：** 基于PID控制的两轮自平衡机器人设计与实现  
**日期：** 2026年  
**实验类型：** 嵌入式系统 / 控制理论  

---

## 1. 实验背景

自平衡机器人是一种典型的倒立摆控制系统。机器人通过实时读取姿态传感器数据，利用PID控制算法驱动电机，使机体在竖直方向保持动态平衡。

该实验涉及嵌入式编程、传感器信号处理、控制理论等多个工程领域，是学习PID控制器的经典入门项目。

**reference:** https://projecthub.arduino.cc/mircemk/arduino-two-weel-self-balancing-robot-edef61

---

## 2. 实验目标

- 理解倒立摆动态系统的控制原理
- 掌握MPU-6050 IMU传感器的数据读取与姿态解算方法
- 实现互补滤波算法，融合陀螺仪与加速度计数据
- 设计并调试PID控制器，实现机器人稳定自平衡
- 了解嵌入式系统的硬件集成与电路设计

## 4. 实验原理

### 4.1 系统模型

自平衡机器人本质上是一个**倒立摆**（Inverted Pendulum）系统。设机体与竖直方向的夹角为 `θ`（俯仰角/pitch），目标为维持 `θ ≈ 0`。

当 `θ > 0`（机体前倾），控制器指令电机向前加速；  
当 `θ < 0`（机体后仰），控制器指令电机向后加速。

### 4.2 姿态解算

**加速度计**：通过重力分量计算静态角度，精度高但对振动噪声敏感。  
**陀螺仪**：对角速度积分求角度，短期精度高但存在积分漂移。

两者互补，使用**互补滤波**融合：

```
angle = α × (angle + gyro_rate × dt) + (1 - α) × accel_angle
```

其中 `α = 0.98`（高通系数），`dt` 为采样时间间隔（秒）。

### 4.3 PID控制器

PID（比例-积分-微分）控制器根据当前误差计算控制输出：

```
error     = target_angle - current_angle
P_term    = Kp × error
I_term    = Ki × Σ(error × dt)
D_term    = Kd × (error - prev_error) / dt

output    = P_term + I_term + D_term
```

`output` 映射到电机PWM占空比（-255 至 +255），正负对应前进/后退。

| 参数 | 作用 |
|------|------|
| Kp（比例增益） | 快速响应误差，过大导致震荡 |
| Ki（积分增益） | 消除静态偏差，过大导致积分饱和 |
| Kd（微分增益） | 抑制震荡，提高阻尼 |

## 5. 实验步骤

### 步骤一：机械组装

1. 将两个N20电机对称固定在底板两侧
2. 安装轮子，确保左右对齐
3. 电池盒固定于底部（降低重心）
4. Arduino、L298N、MPU-6050依次用铜柱固定于上层

> **注意：** 重心位置对控制难度影响显著，重心越高系统响应越慢，调参相对容易。建议初次实验将重心设置偏高（约15cm以上）。

### 步骤二：电路连接

**MPU-6050 → Arduino（I2C）：**

| MPU-6050 | Arduino Nano |
|----------|--------------|
| VCC | 3.3V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

**L298N → Arduino（PWM）：**

| L298N | Arduino Nano |
|-------|--------------|
| IN1 | D5 |
| IN2 | D6 |
| IN3 | D9 |
| IN4 | D10 |
| ENA | D5（PWM） |
| ENB | D10（PWM） |
| GND | GND |

**电源：**
- 电池组（7.4V）→ L298N 12V输入端
- L298N 5V输出端 → Arduino Vin
- 公共 GND 连接所有模块

### 步骤三：读取IMU原始数据

安装 `MPU6050` 库，验证I2C通信，读取原始加速度计与陀螺仪数值，确认数据正常更新。

### 步骤四：实现互补滤波

编写姿态解算代码，计算当前pitch角。在串口监视器中观察角度输出，手动倾斜机体验证响应。

### 步骤五：实现PID控制器

编写PID算法，将控制输出写入L298N，驱动电机。

### 步骤六：PID参数调试

按以下顺序调参：

1. **先调 Kp**：Ki=0, Kd=0，逐步增大Kp直到机器人有明显响应但开始震荡
2. **再调 Kd**：增大Kd直到震荡明显减弱
3. **最后调 Ki**：小幅增加Ki消除静态偏差

> **调参是最耗时的环节，预留足够时间。**

### 步骤七：优化与测试

- 调整重心位置
- 添加电机死区补偿（低速非线性补偿）
- 测试在不同地面（硬地、地毯）上的表现
- 记录平衡时间与抗干扰能力

## 6. 预期结果

| 测试项目 | 预期标准 |
|----------|----------|
| 静止平衡 | 机器人在水平地面可持续平衡 ≥ 30秒 |
| 抗扰动 | 受轻推后能在2秒内恢复平衡 |
| pitch角精度 | 互补滤波输出角度误差 ≤ ±2° |

---

## 7. 注意事项

- 电路连接完成后，上电前务必复查接线，防止短路
- 调试初期应用手扶住机器人，避免摔落损坏器件
- PID输出需做饱和限幅（-255 至 +255），防止溢出
- 互补滤波系数 `α` 默认取 0.98，可根据实际噪声情况微调
- 每次修改参数后需重新烧录并观察足够时间再做判断
