Notes: The applied area of box model is content + padding for the following properties: background-color, background; For box-shadow: applied area is content+margin+border; height,width: applied area decided by property box-sizing Exception: the body's background and background-color's applied area extend to the full page by default set by the browser

block display

Description: An element with display: block takes up the full width of its container by default and starts on a new line, meaning it forces the next element to appear below it.

Block elements by default: <div>, <p>, <h1>, <section>

inline

Description: An element with display: inline only takes up as much width as necessary (it does not break onto a new line) and flows inline with other elements. Margins and padding will not affect the element's layout unless they are applied horizontally inline-block elements by default: <strong>,<span> Notes: width,height are not ajustable, height can be ajusted by line-height.
